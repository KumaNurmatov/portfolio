# Заявки с сайта в Telegram

Попап-бриф на сайте отправляет заявку на маленький обработчик (Cloudflare Worker), а он пересылает её вам в Telegram.
Токен бота хранится только в Cloudflare, в коде сайта его нет. Всё бесплатно.

## 1. Создать бота (2 минуты)

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя (например, «Заявки Курманбек») и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Никому его не показывайте и не отправляйте в чат.
4. Найдите своего бота в поиске и нажмите **Start**, иначе он не сможет вам писать.

## 2. Узнать свой chat id

Напишите [@userinfobot](https://t.me/userinfobot) — он ответит числом `Id: 123456789`. Это и есть **CHAT_ID**.
(Если хотите получать заявки в группу — добавьте бота в группу; id группы начинается с `-100`.)

## 3. Создать воркер на Cloudflare (5 минут)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный план).
2. **Workers & Pages → Create → Create Worker** → назовите `lead` → **Deploy**.
3. **Edit code** → удалите всё и вставьте содержимое файла `telegram-lead.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add**, тип **Secret**:
   - `BOT_TOKEN` — токен из шага 1
   - `CHAT_ID` — число из шага 2
   - `ALLOWED_ORIGIN` — `https://kumanurmatov.github.io` (тип можно Text)
5. Скопируйте адрес воркера сверху: `https://lead.<ваше-имя>.workers.dev`.

## 4. Подключить к сайту

Пришлите адрес воркера Claude — он впишет его в `assets/lead.js` (константа `ENDPOINT`) и зальёт сайт.
Адрес воркера не секретный, его можно держать в коде.

Пока адрес не вписан, опросник работает, а в конце предлагает отправить бриф в WhatsApp с готовым текстом.
