# Заявки с сайта в Telegram + автоответы бота

Как это работает:

1. Клиент проходит бриф на сайте → заявка сразу приходит вам в Telegram.
2. На последнем экране клиент жмёт **«Открыть в Telegram»** → бот моментально отвечает: его бриф, сроки,
   что будет дальше и кнопки «Созвон 15 минут», «Дополнить бриф», «Похожие работы».
   Вам приходит уведомление «🔥 клиент открыл бота».
3. Всё, что клиент пишет боту (текст, файлы, референсы), пересылается вам. Чтобы ответить —
   сделайте **reply** на пересланное сообщение, бот передаст ответ клиенту от своего имени.
4. Если клиент выбрал время созвона — придёт уведомление «📞 хочет созвон: завтра».

Токен бота хранится только в Cloudflare, в коде сайта его нет. Всё бесплатно.

## 1. Создать бота (2 минуты)

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — например «Курманбек · бриф», username — любой свободный, заканчивается на `bot`.
3. BotFather пришлёт **токен** `1234567890:AA...` — никому его не показывайте и не присылайте в чат.
4. Найдите своего бота и нажмите **Start**.
5. По желанию: в BotFather `/setuserpic` — поставьте аватар (логотип или фото).

## 2. Узнать свой chat id

Напишите [@userinfobot](https://t.me/userinfobot) — он ответит `Id: 123456789`. Это **CHAT_ID**.

## 3. Создать воркер на Cloudflare (5–7 минут)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный план).
2. **Storage & Databases → KV → Create** → назовите `leads`.
3. **Workers & Pages → Create → Create Worker** → имя `lead` → **Deploy**.
4. **Edit code** → удалите всё, вставьте содержимое `telegram-lead.js` → **Deploy**.
5. **Settings → Bindings → Add → KV namespace**: Variable name `LEADS`, namespace `leads`.
6. **Settings → Variables and Secrets → Add**:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | токен из шага 1 |
   | `WEBHOOK_SECRET` | Secret | любая длинная строка, например 30 случайных букв и цифр |
   | `CHAT_ID` | Text | число из шага 2 |
   | `BOT_USERNAME` | Text | username бота без `@` |
   | `ALLOWED_ORIGIN` | Text | `https://kumanurmatov.github.io` |
   | `SITE_URL` | Text | `https://kumanurmatov.github.io/portfolio/` |

7. Откройте в браузере `https://lead.<ваше-имя>.workers.dev/setup?key=<WEBHOOK_SECRET>`.
   Должно появиться `"webhook": {"ok": true ...}` и `"kv": true` — бот подключён.

## 4. Подключить к сайту

Пришлите Claude адрес воркера (`https://lead.<ваше-имя>.workers.dev`) — он впишет его в `assets/lead.js`
и зальёт сайт. Адрес не секретный. Токен и WEBHOOK_SECRET присылать не нужно.

Пока адрес не вписан, опросник работает, а бриф уходит в WhatsApp с готовым текстом.

## WhatsApp

Автоответы в обычном WhatsApp без платного API сделать нельзя. Но в приложении **WhatsApp Business**
есть встроенные: Настройки → Инструменты для бизнеса → **Приветственное сообщение** и **Быстрые ответы** —
включите их, и клиенты из WhatsApp тоже будут получать моментальный ответ.
